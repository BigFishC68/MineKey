# MineKey 11 键 + EC11 旋钮 · 使用说明书

> 适用于 `MineKey v1.3` + 固件 `v0.10`（协议 v1）
> 硬件：CH552G + 11 个热插拔轴座 + EC11 编码器 + 11 颗 WS2812

---

## 一、三步上手

1. **连上键盘**（可选）：插 USB → 打开配置器 → 点「连接设备」。
   没有实物就点「演示模式」，除了写硬件，其它都能玩。
2. **点左边一个键 → 右边设功能 → 点「写入此键」**。
   写入是**立即生效**（RAM 里改了），但**掉电会丢**。
3. 全部设好后，去「设备」页点 **「保存到 Flash」**，以后上电就是这个配置。

> 想反悔：点「恢复出厂」；想备份：点「导出配置 .json」。

## 二、硬件与编号

### 2.1 配列与编号

**编号规则：从左到右、从下到上**（与板子丝印 CN1–CN11 一致）。

```
        ┌──────┬──────┬──────┬───────┐
  上排  │ CN9  │ CN10 │ CN11 │ 旋钮  │
        ├──────┼──────┼──────┼───────┤
  中排  │ CN5  │ CN6  │ CN7  │ CN8   │
        ├──────┼──────┼──────┼───────┤
  下排  │ CN1  │ CN2  │ CN3  │ CN4   │
        └──────┴──────┴──────┴───────┘
```

界面上「按键 N」= **CN N**：左下角是 1，往右 2、3、4，上一行 5–8，再上一行 9、10、11，**旋钮在右上角**。

### 2.1.1 出厂键位

| 排 | 第 1 列 | 第 2 列 | 第 3 列 | 第 4 列 |
|---|---|---|---|---|
| 上排 | CN9 = **9** | CN10 = **0** | CN11 = **Backspace** | 旋钮 |
| 中排 | CN5 = **5** | CN6 = **6** | CN7 = **7** | CN8 = **8** |
| 下排 | CN1 = **1** | CN2 = **2** | CN3 = **3** | CN4 = **4** |

旋钮：顺时针 音量 +、逆时针 音量 −、按下 静音。
出厂灯效：呼吸 / 亮度 30% / `#F77634` 全填。

改完键位**不用手动点保存**——配置器会在你停手 0.7 秒后自动写进 DataFlash
（日志里会出现「已自动保存到 DataFlash」）。「设备 → 恢复出厂」会回到上面这张表。

> 若界面上的 CN 标签和板子丝印**对不上**（例如按物理 CN1 出的是 `4`），那是 2026-11-11 18:30
> 之前固件的"行扫描方向反了"的老问题，烧新版 `firmware/minekey.hex` 即修正；烧完 DataFlash
> 里的旧配置会因版本号变化自动作废并回出厂表，不需要手动恢复出厂。

### 2.2 电气矩阵（和原理图对应）

| | C1 | C2 | C3 | C4 |
|---|---|---|---|---|
| **R1** | CN1 | CN2 | CN3 | 编码器按压 |
| **R2** | CN4 | CN5 | CN6 | CN7 |
| **R3** | CN8 | CN9 | CN10 | CN11 |

- 每个轴座串一颗 1N4148W，**阴极朝列线**，所以扫描方式固定为「列输出低、行读上拉」。
- 配置器里选中键时显示的 `矩阵 R1C1` 就是上表坐标 —— 这是**电气**坐标。
- ⚠️ **电气行 ≠ 界面行**：编号是按物理位置排的，矩阵按走线排，两者错开一格：
  `CN4` 在界面下排最右，电气上是 **R2C1**；`CN8` 在界面中排最右，电气上是 **R3C1**；
  旋钮在界面右上角，电气上是 **R1C4**。排错时以 `矩阵 RxCy` 为准，那是万用表能对上的坐标。
- 排查用：某个键不响应时，先看它是不是整行或整列都不响应。

### 2.3 旋钮

EC11 编码器（EC11E15244G1）。固件做 **4 倍频正交解码**：转一格产生 4 个边沿，
累计 4 个边沿算 1 个"刻度"，所以「计数」加 1 就是转了一格。
三向独立可编程：

- **逆时针**（CCW）
- **顺时针**（CW）
- **按下**（相当于第 12 个按键，走同一个矩阵位 R1C4）

方向接反了不用改线：在旋钮编辑区把「方向」改成「反转」即可。

## 四、给按键分配功能

### 4.1 功能类型一览

| 类型 | 值 | 能干什么 | 举例 |
|---|---|---|---|
| 禁用 | `0` | 这个键不产生任何输出 | 暂时不用的位置 |
| 键盘按键 | `1` | 发一个标准 HID 键码 | A、F5、方向键 |
| 多媒体 | `2` | 音量、播放、计算器等 | 音量 + |
| 鼠标 | `3` | 左/右/中键、滚轮上下 | 左键单击 |
| 内部动作 | `4` | 键盘自己执行，不经过电脑 | 亮度 +、切灯效 |
| 组合键 | `5` | 修饰键 + 一个普通键，同时按下 | Ctrl+C、Win+E |
| 主机动作 | `6` | 让电脑上的软件开网页 / 开程序 | 打开 B 站 |
| 光标移动 | `7` | 让鼠标指针往上下左右挪 | 光标 ↑ |

### 4.2 键盘按键

选「键盘按键」→ 在「具体值」里挑。列表就是标准 HID Usage（A–Z、0–9、F1–F12、方向键……）。

也可以直接把修饰键本身映射给一个键（列表最下面：「左 Ctrl」「右 Shift」等），
按住它就等于按住 Ctrl —— 这是"真正的修饰键"，不是组合键。

### 4.3 多媒体 / 鼠标 / 光标移动

多媒体发的是 Consumer Control（Report ID 2），鼠标是 Report ID 4。
鼠标的"滚轮上/下"和左右中键都是**按下沿发一次**；要连续滚动得配合主机动作或改固件。

**光标移动**（类型 7）不一样，它是**按住连发**。选中一个光标键时，右侧会出现
**「灵敏度」滑杆**（16 档，只对这个键生效）：

| 档位 | 每 20 ms 位移 | 速度 |
|---|---|---|
| 0 | 6 px | 300 px/s |
| 5 | 16 px | 800 px/s |
| 10 | 26 px | 1300 px/s |
| 15 | 36 px | 1800 px/s |

档位编在功能码低字节的高 4 位（`0x07XY`，X=档位 Y=方向），`0x0701` 这种老码就是档位 0，
向后兼容。滑杆松手才写入设备，拖动过程中不会反复存盘。

**连击提速**（不用进配置器，直接按就能用）：

| 操作 | 倍率 |
|---|---|
| 单击后按住 | ×1（滑杆设定的速度） |
| 快速双击后按住 | ×2 |
| 快速三击后按住 | ×3 |

判定窗口默认 **400 ms**（松手后多久内再按算连击），可在同一面板的「连击窗口」滑杆上改：
5–40 格 = 100–800 ms，全局生效、存在键盘里，换电脑也带着。

**上下左右一起按（斜着走）不会触发连击**——只有"手上没按住别的方向键"时才算一次点击，
所以斜向移动不会被误判成双击、速度也不会莫名翻倍。

**鼠标滚轮**（左/右键、滚轮上/下）是按下沿发一次，但**滚轮支持长按连发**：
按住 300 ms 后开始每 60 ms 滚一格，松开即停。所以想连续翻页直接按住就行，
不用一格一格点。

斜着走：把两个键同时按住（上 + 右）会合成对角线位移，同样可用。
注意 Windows 的"指针速度"设置会再乘一次，所以不同电脑手感略有差别。

### 4.4 内部动作

键盘固件内部处理，不发给电脑：

| 编号 | 动作 | 说明 |
|---|---|---|
| 2 | 亮度 + | 每次 +5%，到顶钳 100% |
| 3 | 亮度 − | 每次 −5% |
| 4 | 下一个灯效 | 在 0–7 八种灯效里循环 |
| 5 | 重新加载配置 | 从 DataFlash 重读（改坏了可以用它救） |
| 6 | 恢复出厂设置 | 写回默认值并落盘 |

> 编号 1 是保留的「层」标志（状态报文第 5 字节会置 1），固件目前**没有第二层键表**，
> 所以设成 1 不会切换任何东西 —— 别拿它当 Fn 用。

### 4.5 组合键（重点，原理见第五章）

1. 功能类型选「组合键」
2. 下面出现修饰键勾选框：Ctrl / Shift / Alt / Win，**可以多选**
3. 「具体值」选那个普通键（比如 S）
4. 点「写入此键」

键帽上会显示成 `Ctrl+Shift+S` 这样的文本。

### 4.6 主机动作

见第八章。简单说：类型选「主机动作」，具体值选槽位 1–12（内部编号 0–11，界面上从 1 开始），槽位内容在「动作」页编辑。

### 4.7 写入与保存

- 「写入此键」：改 RAM，**立刻生效**，拔电就丢
- 「设备 → 保存到 Flash」：写进 DataFlash，掉电保留
- 「设备 → 恢复出厂」：清回默认键表 + 默认灯效，并保存

## 五、修饰键的运行原理

### 5.1 电脑眼里的"键盘"是什么

USB HID 键盘每按一次，就向主机发一个 8 字节的报告（本键盘 Report ID = 1，长度 8）：

```
字节 0 : 修饰键位图（8 个 bit，一个 bit 一个修饰键）
字节 1 : 保留（厂商用，一般是 0）
字节 2-7 : 6 个"普通键"的键码（最多同时 6 个）
```

字节 0 的位定义（HID Usage 0xE0–0xE7）：

| bit | 7 | 6 | 5 | 4 | 3 | 2 | 1 | 0 |
|---|---|---|---|---|---|---|---|---|
| 键 | 右 Win | 右 Alt | 右 Shift | 右 Ctrl | 左 Win | 左 Alt | 左 Shift | 左 Ctrl |

**关键点：修饰键不是"键码"，而是一个独立的位图。** 所以 Ctrl 和 S 不是先后关系，
而是同一次报告里两个字段同时有值：

```
按 Ctrl+C 时发的报告：
  [0x01, 0x00, 0x06, 0x00, 0x00, 0x00, 0x00, 0x00]
   ↑Ctrl        ↑C
松开时发全 0：
  [0x00, 0x00, 0x00, 0x00, 0x00, 0x00, 0x00, 0x00]
```

主机看到的是一个"组合状态"，它自己决定这是复制还是别的。
**这也解释了为什么组合键不需要"先按 Ctrl 再按 C"的时序** —— 它是一次原子操作。

### 5.2 本键盘怎么表示组合键

一个键只有一个 16 位功能码：`code = (类型 << 8) | 值`。组合键的类型占 4 位修饰位：

```
0x5 M K K
 │  │  └── 普通键的 HID 键码（1 字节，0x04–0x63）
 │  └───── 修饰位（1 字节的低 4 位：1=Ctrl 2=Shift 4=Alt 8=Win，可 OR）
 └──────── 类型 5 = 组合键
```

例：**Ctrl+Shift+S** = `0x5000 | (0x03 << 8) | 0x16` = **`0x5316`**
（0x03 = Ctrl|Shift，0x16 = S）

### 5.3 固件怎么处理

`app.c` 里每个按键在按下时把自己的功能码交给 `apply_code()`：

```c
case 0x05:                                  /* 组合键 */
    *mods |= (uint8_t)((code >> 8) & 0x0F); /* 修饰位并进字节 0 */
    add_usage(keys, n, v);                  /* 普通键码进字节 2-7 */
    break;
```

然后 `build_reports()` 把所有**当前按下的键**的修饰位 OR 在一起、键码去重后塞进 6 个槽位，
和上一次发过的比较，**只有变化了才发新报告**（避免每毫秒刷屏）。

所以：

- 同时按住 `Ctrl+C` 的键和 `Shift+Tab` 的键 → 主机收到的是 `Ctrl+Shift+Tab`（修饰位会叠加）
- 同一个键按住不放 → 只发一次，松开时发一次"全 0"，这正是键盘该有的行为
- 普通键最多 6 个（6KRO），第 7 个会被丢掉；修饰键不受这个限制

### 5.4 常用组合键速查

在「高级 · 原始功能码」里直接填右边这一列也能用（格式 `0x0000`）：

| 组合 | 修饰位 | 键码 | 完整功能码 |
|---|---|---|---|
| Ctrl + C | 0x01 | 0x06 | `0x5106` |
| Ctrl + V | 0x01 | 0x19 | `0x5119` |
| Ctrl + X | 0x01 | 0x1B | `0x511B` |
| Ctrl + Z | 0x01 | 0x1D | `0x511D` |
| Ctrl + A | 0x01 | 0x04 | `0x5104` |
| Ctrl + S | 0x01 | 0x16 | `0x5116` |
| Ctrl + Shift + Z | 0x03 | 0x1D | `0x531D` |
| Ctrl + Shift + Esc | 0x03 | 0x29 | `0x5329` |
| Alt + Tab | 0x04 | 0x2B | `0x542B` |
| Alt + F4 | 0x04 | 0x3D | `0x543D` |
| Win + D | 0x08 | 0x07 | `0x5807` |
| Win + E | 0x08 | 0x08 | `0x5808` |
| Win + L | 0x08 | 0x0F | `0x580F` |
| Win + Shift + S | 0x0A | 0x16 | `0x5A16` |
| Win + Tab | 0x08 | 0x2B | `0x582B` |

> 校验方法：`0x5` + 修饰位 + 键码。例如 Win(8)+Shift(2)=0x0A → `0x5A16`。

### 5.5 做不到的事

| 想干 | 结果 | 原因 |
|---|---|---|
| Ctrl + Alt + Delete | ❌ | 属于 SAS 安全注意序列，操作系统只认物理键盘的特定路径，普通 HID 键盘发不出来 |
| Fn 组合（Fn+F1） | ❌ | Fn 在大多数键盘上是硬件直连 EC 的，不经过 USB 报告；本键盘没有 EC，也没有第二层键表 |
| 一个键发两个不同普通键（宏） | ❌ | 一个键只有一个 16 位功能码，按键里没有"序列"概念。要宏请用主机动作 |
| 组合键里再套组合 | ❌ | 同上，只能"多个修饰 + 1 个普通键" |
| 长按连续触发（比如按住音量 +） | ⚠️ | 多媒体键是按下沿单次触发；键盘键没有自动重复（系统会自己产生重复字符） |

## 六、旋钮

点左边旋钮（或键位图右上角那个圆）→ 右侧变成旋钮编辑器：

| 字段 | 说明 |
|---|---|
| 逆时针 → | 反方向转一格发什么 |
| 顺时针 → | 正方向转一格发什么 |
| 按下 → | 编码器按下发什么（等同第 12 个键） |
| 方向 | 觉得转反了就选「反转」 |

三个字段都能选键盘 / 多媒体 / 内部动作（不支持组合键和主机动作的复杂场景；
选了内部动作就是键盘自己执行）。

没接硬件也能试：用鼠标**按住旋钮拖动**，按转过的角度模拟旋转，计数会跟着变。

## 七、灯光与电流

- **8 种灯效**：常亮 / 呼吸 / 彩虹 / 按压缩放 / 关闭 / 彩虹呼吸 / 单点扫描 / 星光闪烁
- **全局**：亮度、速度、主色
- **单键**：选中某个键后改「此键颜色」，或点「此键用主色」「熄灭此键」
- **批量**：「全填主色」「彩虹铺满」

### 电流上限 400 mA

配置器实时估算：`11 mA（主控） + 每颗灯 (1 mA + 19 mA × 亮度占比)`。
超过 **400 mA** 时进度条变红、「下发光效」按钮变灰并拒发。
固件里还有一道兜底（`LED_SUM_LIMIT`），即使收到超标的配置也会整帧等比压暗。

> USB 2.0 端口上限 500 mA，留 100 mA 余量给主控和浪涌。
> 想更亮就改外部供电，别硬拉亮度。

## 八、主机动作（让键开网页 / 开软件）

**键盘自己开不了网页。** USB 键盘只会发键码，它不知道什么是浏览器。
所以链路是：

```
按键 → 固件判定"这是主机动作 3" → 发 Report ID 5, 数据 [3]
                                        ↓
                     电脑上的程序读到 → 执行动作表里第 3 项
```

### 8.1 在配置器里做

1. 「动作」页：选槽位 → 填名称、类型、目标
2. 「按键」页：把这个键设成「主机动作」，具体值选刚填的槽位
3. 点「导出 actions.json」，把文件放 `tools/host-agent/` 下

| 类型 | 目标写法 | 怎么填 |
|---|---|---|
| 网页 | `https://www.bilibili.com` | 直接输入，没写 `https://` 会自动补 |
| 软件 | `C:/Program Files/…/Code.exe` | **选完类型会直接弹文件对话框**，或点「浏览」 |
| 文件夹 | `D:/work` | **选完类型会直接弹文件夹对话框**，或点「浏览」 |
| 命令 | 任意命令行（`cmd /c` 执行，谨慎） | 手输 |

> 「软件 / 文件夹」的路径是**桌面版**才能选的（浏览器不给网页读本地路径）。
> 用网页版就手动敲路径，或者改用桌面版。

### 8.2 试跑

「动作」页的 **「试跑此槽位」** 会立刻执行一次**当前编辑的槽位**，用来验证目标写得对不对：

- **桌面版**：由宿主用 ShellExecute 真实执行（网页/软件/文件夹/命令都行），和双击文件一个效果
- **网页版**：只能开「网页」类型，其它类型浏览器沙箱里做不到

### 8.3 常驻代理（不打开配置器也能用）

**临时用**：双击 `tools\host-agent\start_agent.bat`（有窗口，能看见每次触发的日志）。

**一劳永逸**：双击 `tools\host-agent\install_autostart.bat`

- 在「启动」文件夹建快捷方式，用 `pythonw.exe` **后台运行，没有黑窗口**
- 开机登录自动起，立刻也会启动一次
- 日志写在 `tools\host-agent\agent.log`（超过 1 MB 自动重来）
- 撤销：双击 `uninstall_autostart.bat`（会同时停掉后台进程）

命令行等价写法：

```bash
cd tools/host-agent
pip install hidapi          # 只需一次；本机已装（D:\Python）
python agent.py -c actions.json                       # 前台，看日志
pythonw agent.py -c actions.json --log agent.log      # 后台，写文件日志
```

首次运行如果没有 `actions.json`，会自动从 `actions.example.json` 复制一份 ——
**这份是你自己的，不会进 git**。

代理常驻后台，收到 Report ID 5 就查 `actions.json` 执行。
**改功能只改 json，不用重烧固件。**

> 主机动作**必须**有这个代理在跑，不跑就什么都不会发生——这是设计如此：
> 键盘只能发键码，开网页/开软件得由电脑上的程序来做。
>
> 程序内有**命名互斥体**，开机自启和手动启动同时存在时只会保留一份，
> 不会出现"按一次键开两个窗口"。

## 十、常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 点「连接设备」提示未找到 | 板子没插 / 不是这块板（VID:PID 不匹配）/ 被别的程序独占了厂商接口 |
| 改了键没反应 | 只写了 RAM 没写 Flash？先确认「写入此键」成功，再「保存到 Flash」 |
| 某个键没反应 | 看是不是整行/整列都不响应（矩阵问题）；单个键先查轴和二极管方向 |
| 组合键变成了普通键 | 组合键的键码必须在 0x04–0x63，太靠后的功能键要手动填原始码 |
| 按了组合键，电脑收到的是两个修饰 | 正常：修饰位和键码在同一次报告里，系统会同时看到 |
| 灯效下发失败 | 电流超 400 mA，降亮度或减少亮灯数 |
| 灯颜色不对（比如全绿） | WS2812 位翻转时序没标定，改 `app.c` 里 `ws_send_byte` 的 nop 数 |
| 误操作把配置弄坏 | 设一个键为「内部动作 5（重新加载配置）」或 6（恢复出厂） |
| 换电脑后动作失效 | 那台电脑没跑 host-agent，或 `actions.json` 没带过去 |

## 十一、功能码速查

`code = (类型 << 8) | 值`，写成 4 位十六进制：

| 类型 | 高字节 | 例子 |
|---|---|---|
| 禁用 | `0x00` | `0x0000` |
| 键盘 | `0x01` | `0x0129` = Esc，`0x013A` = F1，`0x01E0` = 左 Ctrl |
| 多媒体 | `0x02` | `0x0201` = 音量 + |
| 鼠标 | `0x03` | `0x0301` = 左键单击 |
| 内部动作 | `0x04` | `0x0402` = 亮度 + |
| 组合键 | `0x5M` | `0x5316` = Ctrl+Shift+S |
| 主机动作 | `0x06` | `0x0603` = 执行动作槽位 3（槽位编号从 0 起，界面上显示 4） |
| 光标移动 | `0x07` | `0x0701` = 光标 ↑，`0x0704` = 光标 → |

> 完整的 HID 键码表在 `docs/02-软件架构与协议.md` 第 3 章；
> 想手改某个键又不想点菜单，用「高级 · 原始功能码」直接填这四位数最快。
